# Retirement Countdown

A simple responsive retirement countdown page built with HTML, CSS, and JavaScript.

## Features

- Live countdown showing years, months, days, hours, minutes, and seconds
- Responsive layout for desktop and mobile
- Custom background color picker
- Saves the selected color in the browser
- Automatically removes countdown units as they reach zero
- Large "RETIRED" message when the countdown ends
- Fireworks celebration at retirement
- Basic accessibility support
- No external libraries or dependencies

## Hosting

Hosted with GitHub Pages.
